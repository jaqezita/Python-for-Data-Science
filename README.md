Este repositório contém as soluções desenvolvidas durante a **Piscine de Python para Ciência de Dados** da [42 São Paulo](https://www.42sp.org.br/). O objetivo deste currículo é aprofundar os conhecimentos em Python, focando em manipulação de dados, análise numérica e paradigmas de programação.

---

## 📋 Sobre o Projeto

A Piscine é composta por uma série de módulos que evoluem em complexidade, cobrindo desde a sintaxe básica do Python até o processamento de dados em larga escala.

### Módulos

| Módulo | Tema | Status |
|--------|------|--------|
| **00 - Starting** | Sintaxe básica, tipos de dados e funções | ✅ Concluído |
| **01 - Array** | Vetores e matrizes com **NumPy** | 🔜 Em breve |
| **02 - DataTable** | Tabelas, CSVs e análise exploratória com **Pandas** | 🔜 Em breve |
| **03 - OOP** | Programação Orientada a Objetos | 🔜 Em breve |
| **04 - DOD** | Data Oriented Design e otimização de performance | 🔜 Em breve |

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/jaqezita/Python-for-Data-Science.git
   ```

2. **Acesse o exercício desejado:**
   ```bash
   cd Python-for-Data-Science/0-Starting/ex00
   ```

3. **Execute o script:**
   ```bash
   python3 Hello.py
   ```

## 💡 Exercícios — Módulo 00 (Starting)

| Exercício | Arquivo | Descrição |
|-----------|---------|-----------|
| ex00 | `Hello.py` | Demonstra mutabilidade/imutabilidade de `list`, `tuple`, `set` e `dict` |
| ex01 | `format_ft_time.py` | Exibe os segundos decorridos desde 01/01/1970 (Unix Epoch) em dois formatos |
| ex02 | `find_ft_type.py` | Recebe qualquer objeto e imprime seu tipo formatado |
| ex03 | `NULL_not_found.py` | Identifica e exibe valores nulos: `None`, `NaN`, `0`, `""` e `False` |
| ex04 | `whatis.py` | Recebe um inteiro por `argv` e informa se é par ou ímpar |
| ex05 | `building.py` | Recebe uma string e conta maiúsculas, minúsculas, pontuação, espaços e dígitos |
