# 42 Piscine - Python for Data Science 🐍

Este repositório contém as soluções desenvolvidas durante a **Piscine de Python para Ciência de Dados** da 42. O objetivo deste currículo é aprofundar os conhecimentos em Python, focando em manipulação de dados, análise numérica e paradigmas de programação.

---

## 📋 Sobre o Projeto

A Piscine é composta por uma série de módulos que evoluem em complexidade, cobrindo desde a sintaxe básica até o processamento de dados em larga escala.

### Conteúdo dos Módulos:

* **Módulo 00 - Starting:** Introdução ao ambiente, sintaxe, tipos de dados e funções básicas.
* **Módulo 01 - Array:** Manipulação de vetores e matrizes utilizando a biblioteca **NumPy**.
* **Módulo 02 - DataTable:** Trabalhando com tabelas, carregamento de CSVs e análise exploratória com **Pandas**.
* **Módulo 03 - OOP:** Programação Orientada a Objetos aplicada a contextos de dados.
* **Módulo 04 - DOD:** Introdução ao Data Oriented Design e otimização de performance.

---

## 🛠️ Tecnologias e Ferramentas

* [Python 3.10+](https://www.python.org/)
* [NumPy](https://numpy.org/)
* [Pandas](https://pandas.pydata.org/)
* [Matplotlib / Seaborn](https://matplotlib.org/) (para visualização)
* **Conda/Venv** para gerenciamento de ambientes.
